About CODE DNA

CODE DNA is a student project designed to help learners explore source code structure, compare implementations, and understand basic algorithm complexity.

Supported Languages

Java · Python · C · C++ · JavaScript

Features

  • Source code analysis
  • Estimated time and space complexity
  • Basic bracket and structure checks
  • Code fingerprinting
  • Side-by-side code comparison
  • Local analysis history

CODE DNA does not execute programs. Results are educational estimates and should be reviewed by the programmer.
