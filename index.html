What is CODE DNA?

CODE DNA is a learning-focused code analysis project designed to help programmers understand their source code.

Supported Languages

C, C++, Java, Python, and JavaScript.

Supported Topics

Arrays, strings, linked lists, stacks, queues, searching, sorting, recursion, trees, graphs, hashing, dynamic programming, OOP, exception handling, multithreading, and file handling.

Project Goal

Help students explore code structure, common programming patterns, and estimated time and space complexity.
